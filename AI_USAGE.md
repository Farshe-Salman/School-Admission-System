# AI Usage

## AI Tools Used

I used Claude (Anthropic) and ChatGPT (OpenAI) as supporting tools during this project. I did not use AI to generate the entire application and submit the output without understanding or checking it. I completed the main implementation myself and used AI when I needed help with design ideas, technical problems, or debugging.

## 1. UI/UX Design – Claude

I mainly used Claude to explore the initial UI/UX direction and create a clickable design/prototype. This helped me plan the layout and overall user experience before implementation. I treated the design as a starting point, then made my own changes while building the frontend to better match the project requirements and the actual application flow.

## 2. Backend Development – My Implementation with AI Support

I implemented the backend myself using ASP.NET Core, C#, Entity Framework Core, and PostgreSQL. When I became stuck, I sometimes asked ChatGPT or Claude for explanations or possible solutions. This included help understanding errors, reviewing implementation approaches, and exploring topics such as database transactions, concurrency, locking, and business logic.

I did not accept every suggestion automatically. I reviewed the explanation, compared it with the assignment requirements and my existing code, and checked whether it made sense for the application before deciding whether to use it.

## 3. Frontend Development and API Integration

Claude helped me with the initial frontend design direction. I then worked on the React frontend myself, modified the design, adjusted the interface, and connected it to the backend APIs. I used ChatGPT or Claude when I needed help understanding frontend issues, fixing errors, or troubleshooting API integration.

## 4. Checking AI Suggestions and Correcting Mistakes

Some AI suggestions or explanations were not fully correct or did not fit my project. I tried to identify these issues rather than applying the suggestions blindly.

When something looked incorrect, I checked it against the assignment requirements, the actual code, official error messages, build output, API responses, and database behaviour. I also ran the application and tested the relevant flow to see whether the suggested change worked as expected.

If a suggestion caused an error, failed a test, contradicted the required behaviour, or did not match how the project was structured, I went back to the relevant code, investigated the cause, and modified or rejected that suggestion. After making a correction, I rebuilt or reran the application and repeated the relevant test to verify the result.

This checking process was particularly important for backend validation, database operations, concurrency handling, and frontend-to-backend integration. AI suggestions were treated as guidance; the final decisions, code changes, and verification were my responsibility.

## 5. Testing and Debugging

I used AI as a supporting resource to think through possible test scenarios, edge cases, and debugging approaches. I personally ran the application and tests, inspected the results, and checked the database state where necessary. I used the observed results—not an AI response alone—to decide whether the implementation behaved correctly.

## 6. My Overall Approach

My general workflow was:

1. I first tried to understand and solve the problem myself.
2. If I got stuck, I asked ChatGPT or Claude for an explanation or possible approach.
3. I reviewed the suggestion and checked it against the assignment, my code, and the actual error or behaviour.
4. I adapted the suggestion where necessary instead of copying it blindly.
5. I implemented the change, ran the application or relevant tests, and checked the result.

## 7. Summary

Claude was particularly useful for the initial UI/UX design and clickable prototype. I also used ChatGPT and Claude for technical explanations, debugging, and exploring possible solutions. I was responsible for the main backend implementation, frontend modifications, API integration, testing, and checking the final behaviour. When AI suggestions were inaccurate or unsuitable, I investigated the issue, corrected or discarded the suggestion, and verified the fix by running the application or relevant tests.
